# TreasureRun v0.1.12-alpha — Local-only ResourcePack generation

This patch release changes the ResourcePack distribution boundary while preserving TreasureRun's existing runtime localisation features and the v0.1.11-alpha server-safety behavior.

## Changes

- Removed tracked and publicly bundled Minecraft language payload JSON files.
- Removed the generated shared ResourcePack ZIP and its SHA-1/SHA-256 sidecars from the repository.
- Added an operator-local generator that reads Minecraft 1.20.1 language assets from the operator's own installation.
- Marked generated packs `LOCAL_ONLY_DO_NOT_PUBLISH` and recorded them in `local-pack-manifest.tsv`.
- Kept automatic public ResourcePack delivery disabled by default.
- Validated 17 eligible mappings and retained six explicit HOLD mappings without guessing.
- Kept fail-closed behavior: no silent English fallback and no silent `lzh -> lzh` mapping.

## Preserved boundaries

- 23 plugin-owned language YAML files.
- Player language selection and persistence.
- ProtocolLib packet localisation, with ProtocolLib remaining an optional external dependency rather than a bundled library.
- The pure-Java i18n core and Fabric Java runtime.
- Database and ranking behavior.
- v0.1.11-alpha server-safety behavior.
- Third-party license and notice packaging in the server JAR.

## Distribution notes

- Locally generated client packs are operator-local outputs and are not release assets.
- Existing historical GitHub Release assets are not replaced or deleted by the release-preparation change.
- This release does not add `/treasurerun create` or `/treasurerun join`; that remains a separate v0.2.0-alpha milestone.
